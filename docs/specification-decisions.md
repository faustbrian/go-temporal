# Temporal specification decisions

The machine-readable objects below are the exact current records. `ISO8601`,
`ISO80000`, and `Bourbaki` are package format selectors; only the selected
subsets are claimed. Nothing in this package implements Temporal service RPCs,
workflow history, commands, payloads, or compatibility behavior.
